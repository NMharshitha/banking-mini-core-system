# Banking Mini Core System - API Documentation

## Base URL

```text
http://localhost:8080
```

## Overview

The Banking Mini Core System provides RESTful APIs for managing customers, bank accounts, financial transactions, reports, and audit logs. The APIs are built using Spring Boot and follow standard REST architecture principles.

---

# Customer APIs

## 1. Create Customer

**Method:** POST

**Endpoint:**

```text
/api/customers
```

### Request Body

```json
{
  "firstName": "Harshitha",
  "lastName": "NM",
  "email": "harshi@gmail.com",
  "mobileNumber": "9876543210"
}
```

### Response

```json
{
  "customerId": 1,
  "firstName": "Harshitha",
  "lastName": "NM",
  "email": "harshi@gmail.com",
  "mobileNumber": "9876543210"
}
```

---

## 2. Get All Customers

**Method:** GET

**Endpoint:**

```text
/api/customers
```

### Response

Returns a list of all customers.

# Transaction APIs

## 1. Deposit Money

**Method:** POST

**Endpoint:**

```text
/api/transactions/deposit
```

### Request Body

```json
{
  "accountId": 1,
  "amount": 5000
}
```

### Response

```json
{
  "transactionId": 1,
  "transactionType": "DEPOSIT",
  "amount": 5000
}
```

# Validation Rules

### Customer Validation

* First Name is mandatory.
* Last Name is mandatory.
* Email must be valid.
* Mobile Number must contain 10 digits.

### Account Validation

* Customer must exist before creating an account.
* Account Type must be valid.

### Transaction Validation

* Amount must be greater than zero.
* Source account must exist.
* Destination account must exist for transfers.
* Account must have sufficient balance for withdrawal and transfer operations.
